# Simple Line Editor - Help

## Commands

### 1. Insert Line

Adds a new line at the specified line number.

**Usage:**

```text
Choose 1
Enter line number: 1
Enter text: Hello World
```

### 2. Delete Line

Deletes a line from the document.

**Usage:**

```text
Choose 2
Enter line number: 1
```

### 3. Display Document

Displays all lines with their line numbers.

**Usage:**

```text
Choose 3
```

### 4. Save File

Saves the current document to a text file.

**Usage:**

```text
Choose 4
Enter filename: document.txt
```

### 5. Load File

Loads the contents of a text file into the editor.

**Usage:**

```text
Choose 5
Enter filename: document.txt
```

### 6. Search

Searches for a word or phrase in the document.

**Usage:**

```text
Choose 6
Enter word or phrase: Hello
```

### 7. Exit

Closes the line editor.

**Usage:**

```text
Choose 7
```

## Notes

* Maximum number of lines: 100
* Maximum characters per line: 200
* Line numbers start from 1.
* Invalid line numbers are rejected.
